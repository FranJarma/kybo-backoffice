# UI implementation report — Kybo foundation

Implemented the private administration shell, login screen, dashboard, and reusable catalog manager for suppliers, customers, payment methods, ingredients, products, and purchase presentations. The manager provides search, active/archived views, counted/limited results, create/edit/archive/restore, clear empty and failure states, and mobile cards beside desktop tables. Forms preserve draft values after validation, network, and revision conflicts. A network loss after submit reports that the outcome could not be confirmed; it does not claim failure or success. Presentation quantity displays the selected ingredient's base unit. Missing ingredient cost displays **Pendiente**; missing optional prices display **—**. Decimal values stored with a dot are converted to comma-form draft values before edit.

The UI components in `src/components/ui` are the official Shadcn new-york-v4 registry source downloaded from `https://ui.shadcn.com/r/styles/new-york-v4/{button,input,label,card,badge,table,dialog}.json` on 2026-09-25. Only the `cn` and local button import paths were remapped, and the dialog close accessible label was translated. Kybo colors and touch target sizing are configured in `globals.css`. The CLI stalled fetching the registry, so the same registry JSON was downloaded directly and extracted. `components.json` records the registry style and aliases.

`tests/e2e/catalog.spec.ts` covers login, supplier persistence through reload/edit/archive/restore, a stale concurrent revision, an aborted save that retains draft, missing ingredient cost, customer creation without promotional consent, anonymous GET, authenticated foreign-Origin POST, and 390px navigation and overflow. The managed runner in `scripts/e2e-run.ts` supplies a temporary database and account.
