# Registro de incidencias del ensayo manual

Ensayo/carpeta: __________ · Versión: __________ · Fecha: __________ · Responsable: __________

Usar un ID por problema. “Bloqueante” significa que impide terminar el circuito o deja incoherentes stock, cobros, permisos o caja; no continuar los controles dependientes hasta entenderlo.

| ID | Caso del checklist | Cuenta/rol | Venta, pedido o movimiento | Resultado esperado | Resultado observado | Tipo | Impacto | Evidencia | Estado |
|---|---|---|---|---|---|---|---|---|---|
| QA-001 | | | | | | Error / Configuración / Función pendiente | Bloqueante / Alto / Medio / Bajo | | Abierto |

Para reproducir una incidencia:

1. Pantalla y estado previo.
2. Pasos exactos y datos ingresados.
3. Qué sucedió y cuánto tardó aproximadamente.
4. Si se reintentó, cuántas veces y qué se vio en Historial/Caja/Stock.
5. Captura y mensajes visibles. No adjuntar contraseñas ni archivos de la app real.
