# Comandas digitales Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Cola compartida por estación y medición auditable de preparación.
**Architecture:** Módulo preparation con publicación transaccional desde sales; estados y eventos independientes del cobro. UI online con polling visible y reintentos estables.
**Tech Stack:** Next.js 16.3.6, React 19.3, TypeScript 6, Drizzle, PostgreSQL/PGlite, Shadcn. Sin dependencias nuevas.
**Spec:** docs/superpowers/specs/2026-09-25-comandas.md

## Global Constraints

- No publicar, conectar servicios externos ni tocar el sitio original.
- Importes exactos; hora del servidor y fecha comercial de Salta.
- Sin consumo/reservas de stock, offline, push, impresión o fichajes en este incremento.
- Un producto tiene una estación; un pedido admite varias estaciones a través de sus renglones.
- No enviar ventas históricas al migrar. No sembrar datos ficticios.
- Leer documentación instalada de Next antes de editar rutas/componentes. Conservar UI y permisos.

## Review Focus

- Toma simultánea y cancelación: un único responsable, venta bloqueada antes de tarea, sin deadlocks por orden inverso.
- Reintento tras cambios posteriores: no repetir eventos ni devolver una instantánea mixta; GET consistente.
- Estación archivada o ruteo cambiado durante venta: conservar ruta confirmada, sin tareas perdidas.
- Respuesta perdida, recarga, suspensión o filtro cambiado: no escribir con estado no confirmado ni reemplazar una respuesta nueva por una vieja.
- Varias estaciones y entrega parcial: no sumar duración paralela ni incluir pedidos incompletos/anulados en promedios completos.
